# xoop

Personal Whoop → Supabase data sync.

## Setup

```bash
pnpm install
# fill SUPABASE_SERVICE_ROLE_KEY in .env
# run sql/schema.sql in Supabase SQL editor
pnpm auth      # OAuth — opens browser, saves .tokens.json
pnpm sync 30   # sync last 30 days
```
