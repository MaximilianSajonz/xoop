# Privacy Policy — xoop

**Last updated:** 2026-05-13

## Overview

xoop is a personal, single-user application that retrieves the operator's own Whoop fitness data via the official Whoop Developer API for personal analysis and visualization.

## Data collected

xoop accesses Whoop data belonging exclusively to the authenticated user (the operator of this application), including:

- Profile (name, email)
- Body measurements
- Cycles (daily strain)
- Recovery
- Sleep
- Workouts

## How data is used

Data is fetched from the Whoop API and stored in a private database controlled by the operator. The data is used solely for the operator's personal review and analysis. It is never shared, sold, or transmitted to third parties.

## Data storage

Data is stored in a private database instance accessible only to the operator. OAuth tokens are stored locally on the operator's machine.

## Third parties

No data is shared with any third party. xoop communicates only with the official Whoop API endpoints.

## User rights

This application is operated by a single individual for their own personal use. The operator has full control over the stored data and may delete it at any time.

## Contact

For questions about this application, contact the repository owner via GitHub.
